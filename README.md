## CN2 GIA、CTGNet、双向 CN2，差的是哪一段路

同样是「香港 CN2」，三家页面写的根本不是同一件事。

最常见的一种写法是笼统标「双向 CN2 GIA 三网直连」，把电信、联通、移动打包成一句。更细的写法会拆开运营商，例如香港某家服务商在套餐页写明：电信双程 CN2 GIA，联通仅回程 CN2 GIA，移动仅回程 CN2 GIA。差别落在去程上：电信用户从大陆出发和回程都走 GIA，联通和移动用户去程走的是普通线路，只有回程才切到 GIA。

第二种是「CN2GIA + CTGNet」这类组合标签。CTGNet 是中国电信的国际精品网产品线，和 CN2 GIA 不是同一条链路，标在一起通常意味着不同方向或不同业务走不同网络。

第三种是标 AS4809。AS4809 是 CN2 的自治系统号，标出 AS 号至少说明它愿意让你去核对路由，比只写「CN2 线路」四个字有用。

LightLayer 香港优化线路的回程实测数据来自第三方测速页面，按运营商标注的结果是：电信 CN2GIA、联通 CN2GIA、移动 CMI。也就是说移动回程走的是 CMI（中国移动国际），不是 CN2。分地区中位延迟（同一页面数据）：

这组数字是一家第三方平台的测试页结果，不是商家自己的宣传口径，也不是本文实测。它的价值在于给出量级：华南 10ms 上下，华东 30ms 上下，北方和西南 45–55ms。如果你的用户主要在广东和长三角，这个延迟水平和国内跨省访问差不多；如果用户集中在四川、湖北，移动线路那 50ms 以上的数字要有心理准备。

带宽和流量是两件事，但绝大多数套餐页只写其中一个，读者自己换算。

## 按业务场景选，不用全买一遍

**个人博客、静态站、企业展示页**：1 核 1GB / 10Mbps 那档就够，$5/月或者年付 $24.99。日 IP 几千以内，瓶颈在图片大小不在带宽。

**WordPress + MySQL + Redis 跑在一台机器上**：1GB 内存会紧。MySQL 和 Redis 各自要吃几百 MB，系统本身还要留余量。这种情况直接从 1 核 1GB 往上加内存，别指望靠 swap 撑。

**跑视频、做下载站、定期同步大文件**：先看月流量再看端口。10Mbps 不限流量理论上能跑 3.2TB，但前提是端口一直满着；1TB/月配 20Mbps 的实际可用吞吐反而更稳定。

**团队共用、跑 CI 或容器**：看 CPU 核数和内存配比，1 核 1GB 只适合单进程。这一档往上要自定义配置，不要指望在最低档上叠服务。

**需要 Windows 远程桌面**：确认目标套餐的内存是否够跑 Windows Server，以及授权费是否含在价格里。LightLayer 公开资料里没有香港档的 Windows 授权说明，这一项要问。
